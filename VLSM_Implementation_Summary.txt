### Network Topology
- **Core Layer**: R1-CORE (Cisco 2911 Router)
- **Distribution Layer**: SW-CENTRAL (Cisco 2960-24TT Switch)
- **End Devices**: 36+ PCs, 2 printers, 1 Wireless AP

### Configuration Plan
```bash
# Core Router Configuration (R1-CORE)
interface GigabitEthernet0/0  -> 192.168.10.1/24 (Subnet A)
interface GigabitEthernet0/1  -> 192.168.11.1/26 (Subnet B)  
interface GigabitEthernet0/2  -> 192.168.12.1/27 (Subnet C)
interface GigabitEthernet0/3  -> 192.168.20.1/24 (Subnet D)
interface GigabitEthernet0/4  -> 192.168.21.1/26 (Subnet E)
```

### Implementation Steps
1. **Create Core Router (R1-CORE)** - Type: Cisco 2911
2. **Create Distribution Switch (SW-CENTRAL)** - Type: Cisco 2960-24TT
3. **Add PCs** - Type: PC-PT
4. **Add Printers** - Type: Printer-PT (2 units)
5. **Add Wireless AP** - Type: AccessPoint-PT
6. **Connect devices** using pt_add_link commands
7. **Configure Router** with VLSM IP addressing
